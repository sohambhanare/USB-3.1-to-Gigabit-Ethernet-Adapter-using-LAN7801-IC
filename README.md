# USB-3.1-to-Gigabit-Ethernet-Adapter-using-LAN7801-IC
KiCad design of a USB 3.1 Gen 1 to Gigabit Ethernet adapter based on the LAN7801 and KSZ9031RNX. Includes schematic, 4-layer impedance-controlled PCB layout, power supply design, simulations, and manufacturing Gerbers.
